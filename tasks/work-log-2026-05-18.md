## 18:03 → 18:17 | 크로스오리진 인증 401 수정

**내용**: Railway(백엔드) ↔ Vercel(프론트엔드) 크로스오리진 POST 요청에서 쿠키가 전달되지 않아 발생하던 401 오류 해결

- `AuthResponse` record 추가 — 로그인/회원가입 응답 body에 JWT 토큰 포함
- `JwtAuthenticationFilter` — `Authorization: Bearer` 헤더 우선 추출, 쿠키 폴백
- `client.js` — `setToken()` 추가, 모든 요청에 `Authorization: Bearer <token>` 헤더 첨부
- `AuthContext.jsx` — 로그인/회원가입 시 `setToken(res.data.token)` 저장, 로그아웃 시 제거

## 18:17 → 18:42 | CORS Preflight 403 수정

**내용**: 재배포 후 모든 API 요청이 OPTIONS Preflight 단계에서 403으로 막히는 문제 해결

- `SecurityConfig` — `HttpMethod.OPTIONS, "/**"` permitAll 추가
- `setAllowedOrigins` → `setAllowedOriginPatterns` 교체 (와일드카드 + allowCredentials 호환)
- `allowedHeaders`에 `Authorization` 명시적 추가
